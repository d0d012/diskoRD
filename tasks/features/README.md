# Feature Specs

Put brand-new user-visible capabilities here.

Use one file per feature:

```txt
message-search.md
unread-tracking.md
audit-log.md
channel-permissions.md
```

A feature spec should include:

- Goal
- Scope
- Out of scope
- Backend/API changes, if any
- Database changes, if any
- Frontend changes, if any
- Realtime events, if any
- Acceptance criteria

Move or copy a feature into `tasks/active/` only when it is ready to implement.
